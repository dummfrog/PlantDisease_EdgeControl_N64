# 答辩 Q&A

1. 为什么使用 STM32N647？  
STM32N647 具备边缘 AI/NPU 能力，适合把病害识别前移到低功耗端侧。

2. 为什么使用 NPU？  
NPU 可降低云端依赖和网络负载，让现场设备在弱网环境下仍能完成初步诊断。

3. 当前 PC YOLO 和 NPU 的关系？  
PC YOLO 是演示、验证和对照链路；NPU 是正式边缘部署方向。两者使用一致的 8 类语义映射。

4. 为什么使用 L160/L610？  
它提供 4G HTTP 能力，适合农业现场无固定网络的上报场景。

5. 为什么 Dashboard 可以本地，但设备入口必须公网？  
Dashboard 是投屏展示服务；L160/L610 在 4G 网络侧，不能访问电脑 localhost，必须访问公网 HTTPS。

6. 为什么使用 Supabase Edge Function？  
它提供公网 HTTPS 入口、Secrets、服务端校验和安全写库能力。

7. 为什么不让 L160 直接写 Supabase？  
避免设备持有数据库 key，降低泄露和越权风险。

8. 为什么 JSON body 不改还能增强安全？  
认证字段放 Header，Edge Function 用 Secrets 校验，不需要改变业务数据 body。

9. 为什么 token/HMAC 放 Header？  
Header 是传输层认证语义，便于网关和服务端处理，也避免污染设备 JSON v1.0。

10. 如何保证非法设备不能上传？  
校验 device_id、token、HMAC、timestamp、JSON schema，不通过则拒绝写入。

11. RLS 起什么作用？  
禁止匿名直接写表，限制前端只读，保护数据库即使 Data API 暴露也不会随意写入。

12. 如何处理低置信度？  
禁止自动喷药，提示重新采集或人工复核。

13. 如何处理液位低？  
强制 `pump_action = OFF`，告警为 `LOW_LIQUID`。

14. 如何处理电流异常？  
禁止执行机构动作，建议检查泵、风扇、继电器和供电回路。

15. 模型准确率如何？  
以训练集和现场样本卡测试报告为准，交付中提供现场测试记录工具。

16. 现场打印样本卡是否可靠？  
适合演示链路和相对鲁棒性测试，但不能完全代表真实田间分布。

17. 如何证明闭环？  
展示识别结果、处方、执行动作、Edge Function 写库、Dashboard 刷新和告警。

18. 如果 4G 网络不稳定怎么办？  
设备端重试，串口记录失败原因，现场可用模拟脚本验证云端链路。

19. 如果 NPU 没部署完怎么办？  
PC YOLO 作为对照演示，正式 JSON 协议和云端链路不变。

20. 项目创新点是什么？  
端侧 AI、4G 云端上报、专家规则、安全 Header 鉴权、RLS 和 Dashboard 闭环分析结合。

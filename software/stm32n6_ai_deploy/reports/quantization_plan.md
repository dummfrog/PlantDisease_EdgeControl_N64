# Quantization Plan for STM32N6

## Current Model Status

- Current model: `models/best.onnx`
- Format: ONNX FP32
- Input dtype: `float32`
- Output dtype: `float32`
- Weight dtype: `FLOAT`
- Quantization operators: none detected
- ST Neural-ART warnings: many tensors reported as `is not quantized`

## Why INT8 Is Needed

STM32N6 NPU / Neural-ART deployment normally expects or strongly benefits from quantized INT8 execution. The current FP32 model can be analyzed and generated by the STM32N6 CPU path, but NPU deployment should not be considered complete until an INT8 model is analyzed and generated successfully.

## Calibration Dataset

Recommended calibration images:

- Minimum smoke-test calibration: 80 images, 10 per class.
- Preferred calibration: 400 to 800 images, 50 to 100 per class.
- Source: validation/train images from the same dataset distribution used for this model.
- Coverage: healthy and diseased leaves, different lighting, camera distances, leaf positions, and background conditions.

## Output Naming

Do not overwrite:

- `models/best.onnx`
- original `plant_disease_yolo/runs/detect/train30_gpu/weights/best.onnx`
- original `plant_disease_yolo/runs/detect/train30_gpu/weights/best.pt`

Recommended quantized output path:

```text
models/best_int8_stm32n6.onnx
```

## Quantization Verification Checklist

1. Confirm input remains compatible with firmware preprocessing: RGB, `224x224`, NCHW.
2. Confirm class order remains exactly the same as `models/labels.txt`.
3. Compare FP32 ONNXRuntime results with INT8 ONNXRuntime or ST validation results on the same image set.
4. Accept only if accuracy drop is acceptable for the project defense and hardware demo.
5. Rerun `stedgeai analyze --target stm32n6 --st-neural-art` on the INT8 model from an ASCII-only path.

## Risks

- Quantization may reduce confidence on borderline disease samples.
- Camera preprocessing mismatch can cause larger accuracy loss than quantization itself.
- The current workspace path contains Chinese characters; ST Neural-ART failed before completion in this path. Use an ASCII-only working path for the NPU toolchain pass.
